# Support Gear Protocol · cuándo usar cinturón, muñequeras, mangas, agarres

> **Nota · skill 100% general aplicable a cualquier lifter.**

## Concepto · gear es herramienta, no muleta

Los accesorios de apoyo (cinturón, muñequeras, mangas, agarres) son **herramientas** para amplificar técnica que ya dominas. NO son sustituto de:
- Bracing correcto (ver `[[bracing-valsalva]]`)
- Movilidad articular (ver `[[mobility-prehab-by-joint]]`)
- Patrón motor consolidado

**Regla universal**: dominas el lift sin gear primero · añades gear después para amplificar.

## Cinturón

### Cuándo usar (por intensidad)

| Intensidad work-set | Cinturón |
|---|---|
| <70% 1RM | **NO** (construye core) |
| 70-85% | **Opcional** (según fatiga del bloque) |
| >85% | **SÍ recomendado** |
| Test ≥95% | **SÍ obligatorio** para squat y deadlift · opcional bench |

### Cuándo usar (por lift)

| Lift | Cinturón |
|---|---|
| Sentadilla pesada | Sí >80% |
| Peso muerto pesado | Sí >80% |
| Hip thrust >100 kg | Opcional · más por agarre que IAP |
| Press militar de pie pesado | Opcional |
| Bench plano | Raramente · solo competición |
| Accesorios | NUNCA |

### Cómo ajustar

1. **Ajuste medio-apretado**: puedes meter 1 dedo plano entre cinturón y abdomen
2. **NO muy apretado**: si no puedes inhalar 360°, está demasiado apretado
3. **Posición**: parte alta del cinturón a la altura del ombligo o ligeramente arriba
4. **Material**:
   - Cinturón de palanca o doble pin (powerlifting): apto sets pesados ≤5 reps
   - Cinturón velcro: apto sets moderados 5-10 reps

### Cómo respirar contra cinturón

Ver `[[bracing-valsalva]]` integración con cinturón. Resumen:

1. Inhala 360° **empujando contra el cinturón**
2. El cinturón te da feedback táctil de buen brace
3. Valsalva normal · cinturón previene "fuga" lateral

### Cuándo NO usar (construir core)

- Sets de volumen <70% (oportunidad de fortalecer transverso)
- Warm-up (siempre sin cinturón)
- Accesorios (siempre sin)
- Deload (priorizar técnica sin asistencia)

## Muñequeras (wrist wraps)

### Cuándo

| Lift | Muñequeras |
|---|---|
| Bench plano pesado (>85%) | Sí · neutraliza muñecas |
| Press militar pesado | Sí · esencial >85% |
| Curl pesado | Opcional · raramente |
| Sentadilla pesada | Opcional (high-bar más, low-bar menos) |
| Peso muerto | NO (interfieren con grip) |

### Cuánto apretar

- **Moderado**: muñeca firme pero NO acolchada como si fuera escayola
- Si pierdes circulación (dedos azules): demasiado apretado
- Si no notas diferencia: demasiado suelto

### Marca y longitud

- 30-50 cm es estándar
- Stiff (más rígidas): para sets pesados ≤5 reps
- Flexibles (más cómodas): para sets moderados

## Mangas de rodilla (knee sleeves) vs rodilleras (knee wraps)

### Mangas (sleeves) · uso común

| Cuándo | Por qué |
|---|---|
| Sentadilla pesada (>80%) | Calor articular · mejor propiocepción |
| Sentadilla volumen | Opcional · efecto pequeño |
| Hip thrust pesado | Opcional · no son necesarias |
| Test | Sí · si las has usado todo el macro |

### Rodilleras (wraps) · solo competición

- Apretar fuerte alrededor de rodilla
- Devuelven energía elástica · permiten +10-15% más peso
- **NO usar en entrenamiento normal** · estresan articulación
- Solo para competición powerlifting

### Distinción crítica

- **Sleeves** (mangas) = neopreno suave · calor + propiocepción · seguro día a día
- **Wraps** (rodilleras) = elásticos rígidos · asistencia mecánica · solo competición

## Cinchas / lifting straps

### Cuándo

| Lift | Straps |
|---|---|
| Peso muerto pesado (>85%) | Sí · si grip es limitante |
| RDL pesado | Sí · siempre opcional |
| Remo pesado | Opcional · puede tapar debilidad de grip |
| Dominada lastrada pesada | Opcional |
| Sentadilla / bench | NUNCA |

### Cuándo NO

- Sets de volumen del lift donde grip te limita (deja que grip mejore)
- Test de 1RM peso muerto (si quieres ver tu real, sin straps)
- Curl, lateral, accesorios donde grip no es el limitante

### Hook grip (alternativa)

- Pulgar bajo dedos índice y medio
- **No requiere material**
- Más amigable que mixto (evita desbalance bíceps)
- Adaptación: 4-6 semanas de incomodidad
- Una vez adaptado: el mejor agarre para peso muerto pesado

## Calzado

| Lift | Calzado óptimo |
|---|---|
| Sentadilla high-bar | Haltera con tacón 2-3 cm |
| Sentadilla low-bar | Plano duro (Chuck Taylor) |
| Peso muerto | Plano fino o descalzo · NUNCA tacón |
| Bench plano | Plano cualquiera (mejor duro) |
| Hip thrust | Plano · cualquiera |
| Press militar | Plano · cualquiera |
| Curl / lateral / isolation | Plano · cualquiera |
| Cardio Z2 | El que prefieras (running, plano, etc.) |

### Calzado que NO sirve para fuerza

- ❌ Zapatillas de running (mucha amortiguación · pierdes feedback suelo)
- ❌ Tacones (en cualquier lift) excepto haltera específica para squat
- ❌ Descalzo en sentadilla (si gym no permite) · usar plano fino

## Otros gear

### Magnesia / liquid chalk

- Útil para peso muerto pesado (mejora grip)
- Útil para dominada lastrada
- Suele requerir permiso del gym (algunos lo prohíben por suciedad)

### Lifting hooks (ganchos)

- Sustituyen straps · enganchan barra directamente
- Pierden mucho feedback técnico
- Usar solo para emergencia (lesión grip)

### Knee push-up board / paralettes

- Sustituto BW para press
- Para viaje · ver `[[vacation-bw-routine]]`

## Regla universal · NUNCA estrenar el día del test

**No estrenes equipo el día del test bajo NINGUNA circunstancia**:
- Cinturón nuevo → cambia bracing
- Muñequeras nuevas → cambian posición muñeca
- Zapatillas nuevas → cambia stance
- Mangas nuevas → cambia sensación rodilla
- Calcetines nuevos (sí, en serio) → cambia grip suelo en peso muerto

> Test sin sorpresas. Cero novedades materiales.

Si necesitas nuevo equipo: estrenar al menos 2 semanas antes del test, idealmente 4.

## Señales de over-reliance (dependencia excesiva)

Has caído en dependencia si:
- ✗ No puedes hacer sentadilla 70% sin cinturón
- ✗ No puedes brace sin notar el cinturón apretado
- ✗ Muñecas duelen sets ≤70% sin muñequeras
- ✗ Necesitas mangas para sentirte "ok" en sentadilla deload
- ✗ Grip falla en RDL al 60% sin straps

**Solución**: períodos sin gear obligatorios (1 sem cada 4-6 sem) en sets ≤70%. Re-construye lo que el gear tapaba.

## Errores típicos

- ❌ Cinturón en accesorios (D-F)
- ❌ Muñequeras durante curl ligero (innecesario)
- ❌ Strap en bench (no aplica)
- ❌ Mangas para "calentar" (son para sets pesados, no para warm-up)
- ❌ Cinturón muy apretado bloqueando bracing
- ❌ Cambiar cinturón entre marcas mid-macro
- ❌ Test sin equipo cuando entrenas con él (te pierdes 5-10% de techo)
- ❌ Equipo con uso simbólico (te lo pones porque queda bien · NO porque cumple función)
