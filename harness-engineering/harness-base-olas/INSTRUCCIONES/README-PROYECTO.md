## Quick start

1. `bash .claude/bootstrap/init.sh`
2. En Claude Code: *"usa project-bootstrap para adaptar el harness a este repositorio"*.
3. Pide tu primera feature: *"conviértela en feature (feature-kickoff) y planifícala hasta GATE#1"*.

Contrato: `HARNESS.md` · reglas del proyecto: `AGENTS.md` · manual y prompts:
`INSTRUCCIONES/` del repositorio del harness.
