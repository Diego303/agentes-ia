# proyecto-clean

Proyecto con el harness SDD multiagente para Claude Code (bundle `0.5.0`,
perfil `clean`, flujo `simple`).

## Quick start

1. `bash .claude/bootstrap/init.sh`
2. En Claude Code: *"usa project-bootstrap para adaptar el harness a este repositorio"*.
3. Copia un prompt de `FAST-USAGE.md` para tu primera feature.

Manual: `INSTRUCCIONES.md` · contrato: `HARNESS.md` · reglas del proyecto: `AGENTS.md`.
